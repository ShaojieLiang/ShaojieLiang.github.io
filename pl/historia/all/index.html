  • 项目经历 · 2026.09—2026.10

    智慧交通数据分析与停车预测

    个人项目

    基于墨尔本停车与交通数据，完成数据分析、停车状态重建及流式预测原型。

    使用 PySpark、Spark SQL 完成清洗、多表关联、时段分析与区域月度报表。

    预测阶段处理约 2755 万条交通记录、319 万条停车记录，重建 15 分钟粒度停车状态，形成约 24.7 万条建模样本。

    使用 Spark MLlib 构建缺失值填补、类别编码和特征组装流程，对比随机森林与梯度提升树。

    通过 Kafka 与 Spark Structured Streaming 搭建历史数据回放和流式预测原型，核对 32 批回放数据的窗口输出。

    成果与记录

    指定月度报表的本地对照测试中，查询耗时中位数由 25.61 秒降至 12.35 秒，降低约 51.8%，输出结果一致。

    调优后的梯度提升树在同月随机留出测试集上取得 R² 约 0.913，RMSE 较未调优模型下降约 15.4%。

    PySpark / Spark MLlib / Kafka / 流式预测
